# Case-study starter for portfolio agents

Use [case-study-template.html](case-study-template.html) as a **blank starting point** for a new portfolio case study. It keeps the typography, large pain headline, optional quote cards, three-way comparison, chosen screen, and next-test flow used in the [published Claude First Builder example](https://ijidakinro.com/claude-first-builder/). The example is evidence of the layout, not a source of claims for another project.

## Start a new case

1. Copy the HTML into a separate working location. Read the portfolio's [agent instructions](../../AGENTS.md) and [style guide](../../STYLE_GUIDE.md). Do not edit this starter in place for a specific project.
2. Fill every bracketed field: owner, audience, observed pain, first-person motivation, source/date/sample/evidence strength, hypothesis, options A/B/C and their tradeoffs, chosen direction and why, screen captions, next validation question, and business-impact hypothesis.
3. Use verbatim quotes only with a verified source. Remove the quote grid if there are no sourced quotes; add `static-quotes` to its class for still cards. Reduced-motion settings already disable floating. Never invent user findings, shipped features, measurements, or results. Label illustrative mockups and keep business impact a hypothesis until measured.
4. Replace the four mockup blocks with approved images. Supply alt text, image dimensions, source/provenance, and full-size links only for files that exist.
5. Search the completed HTML for `[` and `]`; remove all placeholders. Preview at 1280px and 375px in light/dark, check keyboard focus, reduced motion, overflow, images, links, and browser errors.
6. For publication, place the completed page at `<slug>/index.html`, use a clean `/<slug>/` canonical and matching social metadata, and update navigation only as approved. Obtain owner approval before pushing to `main`.

**Do not publish a filled case study with placeholders.** This starter is publicly readable for agents; keep drafts, private references, review notes, and any confidential assets out of the repository.
